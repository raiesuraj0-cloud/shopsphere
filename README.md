# ShopSphere

A production-quality, responsive e-commerce portfolio application built with React and Vite. ShopSphere includes a curated catalog, persistent shopping cart and wishlist, product discovery, checkout simulation, and polished responsive experiences.

## Features

- 24 realistic products across Electronics, Fashion, Home and Living, and Accessories
- Search, category filters, price filtering, and sorting
- Product detail pages with related products
- Persistent cart and wishlist using LocalStorage
- Quantity controls, totals, delivery options, and empty states
- Validated simulated checkout and order confirmation
- Responsive navigation, toast notifications, testimonials, and accessible controls

## Tech stack

React 19, Vite, React Router DOM, Tailwind CSS, Lucide React, Context API, JavaScript ES6+

## Netlify deployment

1. Push the project to GitHub.
2. In Netlify, choose **Add new site → Import an existing project**.
3. Build command: `npm run build`; publish directory: `dist`.
4. Deploy and copy the live URL shown in the Netlify dashboard.
